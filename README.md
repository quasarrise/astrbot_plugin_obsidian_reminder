# astrbot_plugin_obsidian_reminder

# Obsidian Reminder 插件

本插件使 Astrbot 配合 Obsidian 进行待办事项管理，并附带多源 RSS 新闻简报功能。

## 功能特性

- **待办推送**：按优先级 + 是否超期查询任务清单，早 / 午 / 晚三个时段自动推送，或提示词手动触发，晚间附次日重要任务预告。
- **周复盘**：每周定时自动复盘未完成任务（LLM 生成进度压力分析与下周建议），也可提示词手动触发。
- **待办事项写入 Obsidian**：聊天里用中文自然语言加任务，自动解析日期并写入指定笔记。（删除、修改任务仍需在 Obsidian 里完成，建议使用 Tasks 插件）
- **RSS 新闻简报**：多分组 / 多源，`llm` 模式由 AI 提炼精选，`raw` 模式直接整理标题 + 链接（零 LLM 开销）。

## 安装

- 从 AstrBot 插件市场安装，或将插件目录放入 AstrBot 的 `data/plugins/` 。
- 同机应存在 Obsidian 笔记库，如果 Obsidian 在另一台电脑上，需要使用同步软件来同步 Obsidian 的笔记库。

## 快速开始

1. 在 WebUI 插件设置页填好 **「Obsidian 笔记库路径」**（任务文档所在目录的完整路径）——这是任务功能的**总开关**，留空则全部任务扫描与推送关闭。
2. 至少填一个推送时段（如早 `08:30`）。
3. 向机器人发送 **`!obreg`** 命令绑定当前会话（权限锁：插件只响应已绑定会话的指令）。
4. 完事。到点会自动推送，也可通过指令手动查询。
说明：添加和查询/推送任务、新闻整理的功能不依赖LLM，但周复盘和新闻提炼会使用当前会话设置的LLM。

## 聊天指令

| 指令 | 说明 |
|------|------|
| `!obreg` | 绑定当前会话（首次必做；插件只响应绑定过的会话） |
| `!obadd <任务信息>` | 添加任务，如 `!obadd 明天修手表` （见下方示例） |
| `加个任务/加待办 <任务信息>` | 自然语言加任务（同 !obadd） |
| `今天有什么事/今日任务/查待办` 等 | 自然语言查询当前任务（命中「任务/待办」类关键词 + 短指令语义） |
| `复盘`、`进度` | 手动触发一次实时周复盘 |
| `!news` | 手动触发新闻简报（立即收集全部分组并推送） |

### <任务信息> 示例

添加任务时，程序会自动从自然语言中提取日期与任务文本，日期必须在句首或句尾，与内容间可无间隔、空格或中英文逗号，最后可在方括号中指定写入的文档（仅在任务写入模式为 docs 时有效）：

| 任务信息 | 说明 |
|------|------|
| !obadd 明天修手表 | 自动解析为明天日期 |
| !obadd 25号交总结 | 自动解析为本月25日 |
| 加个任务 新版上线 | 自动设定为今日日期 |
| 加任务 下周二看病 | 可自动解析为下周二日期 |
| 加个待办 买菜，2026年6月23日\[新增事项.md\] | 指定写入文档 |
| 加待办 7月4日交稿\[工作\] | 用触发词指定写入文档 |

支持的日期格式：`YYYY年M月D日` / `YYYY-MM-DD` / `YYYYMMDD` / `今天` / `明天` / `后天` / `大后天` / `(这|本|下|下下)周X`（相对星期）/ `M月D日` / `N号` / `下个月N号`。未识别到日期则写入今天。日期后的内容段原样保留（含时间、标签等文字）。

## WebUI 配置项

| 字段 | 说明 | 留空 |
|------|------|------|
| `vault_path` | 任务文档所在的 Obsidian 笔记库完整路径 | 关闭全部任务功能 |
| `morning/noon/night_push_time` | 早 / 午 / 晚任务推送 `HH:MM` | 该时段不推送 |
| `review_day` | 周复盘日（mon...sun） | 复盘关闭 |
| `review_time` | 周复盘时间 `HH:MM` | 复盘关闭 |
| `review_prompt` | 周复盘 LLM 提示词模板 | 预填默认，可自定义 |
| `news_enabled` | 新闻推送总开关 |   |
| `morning_news_time` / `night_news_time` | 早 / 晚新闻推送 `HH:MM` | 该时段不推送 |
| `news_groups` | 新闻分组（最多 3 组），每组可配多个 RSS 源 | 无分组不推送 |
| `news_prompt` | 新闻 LLM 提炼提示词模板 | 预填默认，可自定义 |
| `task_file` | 日任务文档路径模板，`{{date}}` 替换为日期 | `{{date}}.md` |
| `task_mode` | 任务写入模式：`daily` / `docs` | 默认 daily |
| `task_format` | 任务记录格式：`emoji`(Tasks) / `dataview` | 默认 emoji |
| `task_docs` | 任务写入目标文档列表，可配触发词 | 如任务写入模式为 docs 则必填，不填报错 |

> **新闻分组**：`新闻分组` 下每条 `sources_text` 每行一个源，格式 `名称|网址`（`#` 开头的行忽略）。`mode` 选 `llm`（AI 提炼）或 `raw`（原文链接整理）。示例：

```
FT中文|http://www.ftchinese.com/rss/feed
WSJ中文|https://cn.wsj.com/zh-hans/rss
Solidot|https://www.solidot.org/index.rss
```
